# 📐 Page Object Model (POM) — Design Pattern Notes

A reference repository documenting the **Page Object Model (POM)** design pattern for test automation — covering both **without PageFactory** and **with PageFactory** approaches.

---

## 📖 Overview

This repository contains notes and visual references for understanding and implementing the Page Object Model pattern in Selenium WebDriver test automation. It covers the two main approaches to creating page object classes.

---

## 📚 Topics Covered

### Two Approaches to Page Object Model

| Approach | Description |
|----------|-------------|
| **Without PageFactory** | Using `By` locators and `driver.findElement()` directly |
| **With PageFactory** | Using `@FindBy` annotations and `PageFactory.initElements()` |

### Key Concepts
- Separating locators from test methods
- Code reusability and maintainability
- Actions and validations in page classes
- WebElement vs By locator patterns
